# 画面ワイヤーフレーム — BUYMO C2C

実装済み画面のレイアウト（ASCII）。`[...]`=ボタン/リンク、`( )`=入力、`▤`=画像。

---

## 共通ヘッダー（Header.tsx）
```
┌───────────────────────────────────────────────────────────────┐
│ 🚗 BUYMOC2C     車を探す  ❤お気に入り  💬メッセージ  📋マイページ  [出品する] [ログアウト] │
└───────────────────────────────────────────────────────────────┘
（未ログイン時: 車を探す / ログイン / [無料登録]）
```
